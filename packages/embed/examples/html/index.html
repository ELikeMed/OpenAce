OpenAce Embed SDK

Drop an AI executive assistant into any website with 2 lines of code.

Quick Start (Script Tag)

<!-- 1. Add the script -->
<script src="https://cdn.openaceai.com/ace-embed.min.js"></script>

<!-- 2. Initialize -->
<script>
  OpenAce.init({
    serverUrl: '/api/ace',
    theme: 'dark',
    accentColor: '#6366f1',
    greeting: "Hey! I'm Ace, your AI assistant."
  });
</script>

React / Next.js

// Install: npm install @openace/embed

// Server (pages/api/ace/[...ace].js):
import { createAceServer } from '@openace/embed/server';
export default createAceServer({
  ai: { geminiKey: process.env.GEMINI_API_KEY }
});

// Client (any component):
import { AceWidget } from '@openace/embed';
<AceWidget serverUrl="/api/ace" theme="dark" />

What Ace Can Do

  • Research — Web search, read pages, build knowledge base
  • Pipeline — Find leads, manage CRM pipeline, track contacts
  • Email — Draft and send emails, email campaigns
  • SEO — Analyze SEO, generate blog posts, structured data
  • Social — Post and schedule across platforms (Pro)
  • Forms — Create forms, collect submissions
  • Calendar — Google Calendar integration
  • Deploy — Deploy projects to Netlify, Firebase, SFTP
  • Phone/SMS — Send SMS, make calls via Twilio (Pro)
